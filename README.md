Multiple of 3 Checker — README

✅ Overview

This project is a beginner-friendly C# console application that determines whether a given integer is divisible by 3.
It uses the modulus operator (%) to check the remainder.


---

🛠 Features

Accepts a number from the user

Uses modulus to check if the number is a multiple of 3

Displays clear output

Simple, fast, and easy to understand



---

💻 Technologies Used

C#

.NET Console Application



---

▶️ How to Run

1. Open the project in Visual Studio or any C# IDE


2. Build the project


3. Run the application


4. Enter a number


5. Read the result in the console




---

📄 Sample Input/Output

Input:

Enter a number:
9

Output:

9 is a multiple of 3.

Input:

Enter a number:
10

Output:

10 is NOT a multiple of 3.
